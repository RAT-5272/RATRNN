<h2 align="center">Overview</h2>
<p>
RAT RNN is a full framework for local AI training and inference for conversational and capable LLMs.
</p>
<p>
It includes everything required to:
</p>
<ul>
  <li>Create customiseable multi-stage datasets</li>
  <li>Load and fine-tune pretrained local models</li>
  <li>One-on-one chat loop in your terminal</li>
  <li>Multi conversation scalable inference with a queue</li>
  <li>Supports rich tool use and agentic loops</li>
</ul>
